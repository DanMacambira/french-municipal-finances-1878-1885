# Public data releases

This directory is reserved for reviewed, documented commune-year data. **No verified data have been released yet.**

Do not copy `derived/situation_financiere/output/*` here without manual verification and a release process.

A future release should include:
- `commune_year.csv`: validated commune-year panel (original fields plus harmonized fields).
- `variables.csv`: labels, units, historical definitions, and year availability.
- `source_inventory.csv`: BnF document identifiers, original/printed and PDF page references.
- `validation_report.md`: coverage, unresolved ambiguities, and OCR benchmark.

Confirm the dataset's licensing and BnF reuse attribution before publishing.
