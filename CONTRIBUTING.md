# Contributing

Corrections to OCR and historical variable documentation are welcome.

Please report the year, 1-based PDF page number, left/right table, commune name, printed value, proposed correction and a Gallica source link. Avoid uploading full source PDFs or large raw OCR dumps to issues/pull requests. Do not submit secrets or private API logs.

Changes to numerical values should be justified against the original page image. Do not silently impute missing values or normalize historical differences in fiscal concepts.
